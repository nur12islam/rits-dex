# Contributing to RITS

Thanks for your interest in RITS!

## Current status

RITS is in the planning/foundation stage. The initial goal is a reliable desktop shell and a local-first automation engine.

## Guidelines

- Discuss substantial changes in an issue before starting large work.
- Keep changes focused and easy to test.
- Add or update tests with behavior changes.
- Never include API keys, access tokens, passwords, private messages, or personal data.
- Do not introduce unrestricted shell execution or bypass the action permission gate.
- Document new actions, required permissions, and whether data leaves the device.
- Keep local commands usable without cloud AI.
